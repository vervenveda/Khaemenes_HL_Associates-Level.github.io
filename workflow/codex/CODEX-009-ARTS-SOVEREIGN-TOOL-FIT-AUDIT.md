# Arts Curriculum · Sovereign Tool Fit Audit

The Arts curriculum now uses a shared optional-tool invitation layer rather than hard-coded buttons in individual lessons.

## Rules
- A tool appears only when it directly supports the current activity.
- Maximum two tool buttons per invitation.
- The invitation sits beside the activity sequence, not in the footer.
- Tool choice is optional and never affects mastery.
- Offline materials and learner-chosen software remain valid.
- No purchase, account, public posting, or external application is required.

## Main mappings
Drawing / proportion / portrait / perspective → Sketch Lab, Advanced Sketch, Trace & Draw  
Color → Color Studio, Palette Forge  
Composition / layout → Advanced Sketch  
Photography / evidence → Photo Album Studio  
Portfolio / exhibition → Photo Album Studio, My Art Gallery  
Narrative / experimental prompts → SpinSpire where appropriate

Management-only lessons intentionally receive no tool invitation unless a direct tool fit exists.
