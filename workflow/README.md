# Workflow & Conversation Codex Index

This folder is the durable project-memory layer for the Associate-Level repository.

## Files

- `DIGEST.md` — current high-level status, architecture, decisions, milestones and next priorities
- `DECISIONS.md` — append-only durable decision register
- `codex/CODEX-001-ARTS-PROGRAM.md` — conversation codex for the working-artist Arts concentration
- `codex/TEMPLATE.md` — template for future important-conversation codexes

## Codex rule

Create a new codex when a conversation materially changes:
- credential architecture
- program philosophy
- a course blueprint
- ownership/migration policy
- assessment/mastery policy
- safety boundaries
- student-record architecture
- a major research synthesis used to make curriculum decisions

A codex should preserve:
1. the question/problem
2. the important evidence or research
3. the decision
4. why the decision was made
5. exact blueprint/constraints
6. repository artifacts created
7. unresolved/open next steps

Codexes are summaries of important decisions, not transcripts and not private chain-of-thought records.
