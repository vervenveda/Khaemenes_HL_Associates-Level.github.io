# Shared Hall Library

This directory contains provenance-preserved snapshots of ecosystem halls used by one or more Associate-Level programs.

## Current shared halls

- Philosophy
- World Classics & Humanities
- Law & Governance
- Psychology & Mind
- Business Management
- Financial Hall
- Visual Arts
- Music

Each hall contains:

- `source.html` — the imported source snapshot
- `provenance.json` — original repository, original path, source SHA, intended Associate-Level uses, and migration policy

## Authority boundary

These are **source/reference libraries**. They are not standalone Associate-Level courses merely because they are present here.

When a hall is converted into certificate instruction, the resulting course must live under `courses/core/` or `courses/tracks/` and must define learning outcomes, assessments, evidence requirements, mastery rules, and completion authority.
