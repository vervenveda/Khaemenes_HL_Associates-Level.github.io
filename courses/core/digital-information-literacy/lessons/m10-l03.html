KHL-CORE-104 · Module 10 · Lesson 03

Disclosure, Attribution and Academic Integrity

Follow course rules for documenting meaningful automated assistance.

Digital practice target

Use digital tools in ways that are secure, accessible, attributable and inspectable.

Concept frame

How to use generative and automated systems without surrendering judgment or attribution.

Rule: convenience never removes the need to verify sources, preserve learner ownership, protect private information or make important work recoverable.

Practice

Demonstrate follow course rules for documenting meaningful automated assistance. with a concrete academic or everyday example.
Identify one failure mode or security/accessibility risk connected to this skill.
Create a short checklist another learner could use to verify the work.
Explain what information should be preserved so another person can reproduce or audit the result.
State one privacy, attribution or accessibility consideration that should be checked before sharing.

Evidence artifact

Save a screenshot-free or file-based artifact when possible: checklist, file tree, source log, accessible document, spreadsheet, verification record, permission map or version history.

Reflection

Which part of this workflow would fail first if the original device, website or account disappeared?
