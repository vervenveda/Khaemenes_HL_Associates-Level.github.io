KHL-CORE-103 · Module 07 · Lesson 02

Base Rates and Denominators

Ask what population and denominator a rate actually describes.

Quantitative target

Use numbers to clarify rather than decorate an argument. Every result should preserve units, denominator, population, assumptions and uncertainty where relevant.

Concept frame

How to interpret medical, civic, financial and media statistics responsibly.

Practice

Create a simple numerical example demonstrating ask what population and denominator a rate actually describes.
Explain one common misinterpretation of this idea and how to correct it.
Apply the concept to a public claim in science, health, civics, business or the arts.
State the units, denominator, population or assumptions that a reader would need to interpret the number correctly.
Describe one check you would use to catch a calculation or interpretation error.

Data note

For any real dataset or published statistic you use, record source, date, population, variable definitions, sample size if available, and any limitation that affects interpretation.

Reflection

What would a reader misunderstand if the context or denominator were removed?
