Associate-Level Shared Collegiate Core · 3 Learning Units

World Humanities, Culture & Ethical Inquiry

A 45-hour comparative humanities course in literature, philosophy, ethics, religion, art, history, translation, public memory and cultural interpretation.

Comparative scope

The course uses a world-humanities approach. No single civilization, religious tradition, language, translation, aesthetic canon or philosophical school is treated as the universal default.
