Graphite Pressure, Edge & Value Control

Prerequisite

Review Monday’s medium tests and Tuesday priority.

Target

Produce a small test where one technical variable can be judged clearly.

Common Mistake

Changing pressure, tool angle, surface and value strategy at the same time hides cause and effect.

Segmented Demonstration & Key Cues
01 · Pressure LadderCreate five line-pressure levels from barely visible to dark without tearing the surface.
02 · Value ScaleBuild at least seven distinct values using layering rather than pressing hard immediately.
03 · Edge PairRender one hard edge, one soft edge and one lost edge.
04 · Developed StudyUse graphite to draw a simple observed subject with deliberate value grouping.
Practice Sequence
01 · Warm-UpRepeat the weakest Monday test at small scale.
02 · Controlled ComparisonMake two versions with only one technical variable changed.
03 · Self-CheckName the visible difference.
04 · RetryRepeat the weaker version with one correction.
05 · TransferApply the successful result to the active Week study.
