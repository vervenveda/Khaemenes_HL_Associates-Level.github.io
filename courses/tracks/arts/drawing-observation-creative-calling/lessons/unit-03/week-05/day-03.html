About This Skills Day

Today you isolate hue, value, and saturation so each property can be controlled deliberately. You will make short color tests that change one variable at a time, compare the effects, and transfer one successful color decision into Monday’s final artwork.

Skills & Technique Day supports Week 05 · Hue, Value and Saturation.

Skills & Technique Goals

Control Hue

Change color family without unintentionally changing every other variable.

Control Value

Maintain readable light-dark structure beneath color.

Control Saturation

Compare vivid and muted color intentionally.

Transfer the Skill

Apply one tested color decision to the active Week 5 artwork.

Skill of the Day

Visual Target

Create three small tests where hue, value, and saturation can be compared separately.

Prerequisite Check

Review Monday’s studies and identify which property was hardest to control independently.

Concept

Hue names the color family, value describes lightness/darkness, and saturation describes intensity or vividness.

Common Mistake

Changing hue and value at the same time makes it hard to know which property caused the visual effect.

Segmented Demonstration & Key Cues
01 · Hue ShiftChange the color family while keeping the light-dark structure as stable as possible.
02 · Value ShiftMake a lighter and darker version without treating that change as a new hue problem.
03 · Saturation ShiftCompare vivid and muted versions of the same hue family.
04 · Grayscale CheckTemporarily compare the studies in grayscale or by squinting to test value structure.
05 · Palette DecisionChoose the combination that best supports the intended effect and explain why.
Practice Sequence
Warm-UpCreate three swatches of one hue at different values.
Controlled ExerciseCreate three more swatches of the same hue at vivid, medium, and muted saturation.
Guided PracticeMake a tiny composition twice while changing only one selected color property.
Self-ComparisonState which variable caused the clearest visual difference.
RetryIf multiple variables changed accidentally, repeat the test with tighter control.
TransferApply one successful hue/value/saturation adjustment to Monday’s final artwork.
